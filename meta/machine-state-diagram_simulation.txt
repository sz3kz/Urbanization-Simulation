@startuml
title Simulation Engine State Machine

[*] --> Initialization

Initialization : Construct Simulation
Initialization : Initialize boards
Initialization : Seed random generator

Initialization --> Running

state Running {

    [*] --> PrintBoard

    PrintBoard --> PropagateProbabilities
    PropagateProbabilities --> ExecuteProbabilities
    ExecuteProbabilities --> DecayBuildings
    DecayBuildings --> RecycleBoards
    RecycleBoards --> ResetProbabilities
    ResetProbabilities --> IncrementIteration
    IncrementIteration --> Sleep
    Sleep --> PrintBoard

    PrintBoard : Outputs the board
    PropagateProbabilities : Executes building algorithms to populate probability board
    ExecuteProbabilities : Roll dice and execute random events based on probability
    DecayBuildings : Decay occupied cells, transform / empty them if necessary
    RecycleBoards : Swap previous and next board so we need not allocate a new board again
    ResetProbabilities : Re-default the probability board for next iteration
    IncrementIteration : Increment iteration counter
    Sleep : sleep for a bit to not overclock system
}

@enduml
